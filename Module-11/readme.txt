Redis
Install redis on local machine - https://redis.io/docs/latest/operate/oss_and_stack/install/archive/install-redis/


step-1-> Install wsl (wsl --install) run command in cmd
step-2-> Open wsl (wsl) run command in cmd
step-3-> (sudo apt update) run command in wsl
step-4-> Install redis (sudo apt install redis-server -y) run command in wsl
step-5-> Start redis server (sudo service redis-server start) run command in wsl
